Welcome to SortiFy

SortiFy is a grocery-sorting robot designed especially with elderly users in mind. Place one item at a time under the camera and let the robot recognise and sort it into the correct container.

  1. Press “Start Robot Dashboard”.
  2. When asked, place one grocery item in the camera area.
  3. Wait until the screen says “Place the next item now”.
SortiFy
THE PROJECT ROBOT APP

Grocery Sorting Robot for Everyday Living

What the robot does:
SortiFy uses a camera and an AI model to recognise a grocery item placed in the pick-up area. Once the item is detected, the robot gently picks it up and places it into the correct bin. After sorting, it automatically returns to a safe resting position, ready for the next item.

How it helps elderly users:
SortiFy is designed to make grocery organisation easier and safer. There is no need to bend, lift heavy bags, or sort items manually. The robot guides the user with clear on-screen messages, works one item at a time, and requires only a single button to start. This reduces physical effort and builds independence at home.
